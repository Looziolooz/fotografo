# Solari — Wedding Photography Portfolio

A bilingual (EN/IT) wedding photography portfolio built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.

**[Live Demo →](https://fotografo-five.vercel.app/en)**

---

## EN – English

**Solari** is a demo wedding photography portfolio for a fictional Italian photographer, Noro Solari. It showcases editorial & fine art wedding photography across Italy — from Lake Como to Puglia, Amalfi Coast, Tuscany, and Venice.

### Features

- Bilingual (English / Italian) with full i18n content dictionary
- Infinite scrolling portfolio grid (the "film roll")
- Horizontal per-wedding gallery pages with "next project" navigation
- Smooth scrolling via Lenis
- Full-screen overlay navigation menu
- Self-hosted editorial fonts (Neue + Ogg)
- SEO metadata with OpenGraph support
- Static generation for all routes
- Contact form (front-end only)
- FAQ accordion
- Image processing pipeline (Sharp, WebP output)
- Shadcn/ui components

### Tech Stack

| Technology | Purpose |
|---|---|
| Next.js 16 | Framework |
| React 19 | UI |
| TypeScript | Types |
| Tailwind CSS v4 | Styling |
| Shadcn/ui + Base UI | Components |
| Lenis | Smooth scroll |
| Lucide React | Icons |
| Sharp | Image processing |
