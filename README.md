# Atelier Solari — Wedding Photography

> **Tuscany & Amalfi Coast** · Film · Medium Format · Vintage Luxury

---

## 🇬🇧 English

### Atelier Solari — Wedding Photography in Italy

Atelier Solari is a wedding photography studio based in **Florence and Positano**, specializing in weddings across **Tuscany and the Amalfi Coast**. We shoot with medium format film and digital to capture timeless emotions.

### Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS 4 + custom design system
- **Fonts:** Cormorant Garamond (display) · DM Sans (body)
- **Language:** Italian / English (i18n built-in)

### Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Design System

| Token | Value |
|-------|-------|
| Brand background | `#F5F0EB` |
| Brand accent | `#8B7355` |
| Sepia tone | `#C9A878` |
| Text | `#2C2C2E` |

### Structure

```
src/
├── app/           # Layout, pages, global CSS
├── components/    # Header, Hero, Filosofia, Gallery, Servizi, etc.
├── context/       # LangContext (i18n)
└── lib/           # Translations (it/en)
```

### Build

```bash
npm run build
```
